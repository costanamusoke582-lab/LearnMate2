SYLLABUS FILES
Write what each class should learn, so the teacher stays in scope.

FORMAT (any .md or .txt file in this folder, except files starting with README or EXAMPLE)
  # P5                      <- a class heading: P1-P7 or S1-S6 ("Primary 5" and "Senior 2" also work)
  ## Science                <- a subject heading, spelled like the subject list in the app
  - Topic one               <- unindented bullet or numbered lines become the Topic choices in the sidebar
  - Topic two
  ## Mathematics            <- next subject for the same class
  # P6                      <- next class

RULES THE TEACHER FOLLOWS
- With a syllabus for that class and subject, it teaches only that content, at that class level.
  If a learner asks about something else, it says they will learn it later, gives at most one simple
  sentence, and offers a syllabus topic. Quizzes are limited to the syllabus too.
- Without one, it only keeps to the class level, and the sidebar says so.
- Only the first 6000 characters of one class-and-subject section are used, so keep each short.

After editing, press Stop and then Run in Replit.
